# Business rule checklist

- [ ] Concepts unambiguous
- [ ] States exhaustive for the scope
- [ ] Illegal transitions named
- [ ] Every rule has trigger/condition/action
- [ ] Conflicts have priority
- [ ] Exceptions listed (or explicitly none)
- [ ] No untestable adjectives
- [ ] Policy vs mechanism separated
- [ ] Decision table covers main combinations
- [ ] Acceptance checks can fail a wrong implementation
