# Product quality gates

## L0
- [ ] Behavior clear; no silent scope/rule change

## L1 — before build / handoff
- [ ] Goal & scenario clear  
- [ ] Approach chosen  
- [ ] Light PRD or equivalent  
- [ ] Observable acceptance  

## L2/L3 — before “confirmable PRD” or engineering handoff
- [ ] Real problem stated  
- [ ] Users & scenarios clear  
- [ ] Goals & non-goals clear  
- [ ] Material decisions discussed (not assumed)  
- [ ] Solution choice has rationale  
- [ ] Rules complete enough; conflicts resolved  
- [ ] Main happy + exception paths covered  
- [ ] Interaction behavior clear where relevant  
- [ ] Scope & priority clear  
- [ ] Acceptance criteria testable  
- [ ] No open P0 review findings  
- [ ] Critical assumptions labeled  
- [ ] No unjustified over-scope  
- [ ] No critical product decisions deferred as “figure out in dev”  
- [ ] Document status not forged as user-confirmed  

Fail → return to the incomplete stage. “Considered” without mechanism ≠ done.
